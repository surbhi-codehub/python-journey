# 🚀 Today's 10 Python Missions

1. Create a file named **employee_manager.py**.
2. Create a CSV file named **employees.csv** with the columns: **ID, Name, Department, Salary**.
3. Display a menu with options: **Add Employee**, **View Employees**, **Search Employee**, **Update Employee**, **Delete Employee**, and **Exit**.
4. Use `csv.DictReader()` to read employee records.
5. Use `csv.DictWriter()` to save employee records.
6. Implement the **Add Employee** feature.
7. Implement the **Search Employee** feature using Employee ID.
8. Implement the **Update** and **Delete** features.
9. Keep the menu running until the user selects **Exit**.
10. **Revision:** List the Python concepts used in this project and explain why each one is important.
