# 📚 Today's Topic

## 📑 Introduction to CSV Files

### 🌟 Why are we learning this?

CSV files store data in rows and columns, making them easy to exchange between applications like Excel, databases, and Python programs.

# 🎉 Python Fun Fact

CSV files are one of the most widely used formats for importing and exporting data between spreadsheets, databases, and programming languages.

---

# 🔄 Quick Recap

- The `csv` module simplifies working with CSV files.
- CSV data is organised into rows and columns.
- `csv.reader()` reads CSV data row by row.
- Headers describe the data stored in each column.
