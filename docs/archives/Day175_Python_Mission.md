# 🎉 Python Fun Fact

# 🔄 Quick Recap

- `datetime.now()` returns the current date and time.
- `date()` extracts only the date.
- `time()` extracts only the time.
- `strftime()` formats dates and times.
- `timedelta` performs date arithmetic.
