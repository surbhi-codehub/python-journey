### 🌟 Why are we learning this?

Real-world JSON data is rarely flat. API responses often contain nested dictionaries and lists. Learning to navigate them is an essential Python skill.

# 🚀 Today's 10 Python Missions

1. Import Python's built-in `json` module.
2. Create a nested dictionary representing a student with `name`, `age`, and an `address` dictionary.
3. Add a `subjects` list containing at least three subjects.
4. Convert the nested dictionary into a formatted JSON string using `json.dumps(..., indent=4)`.
5. Print the formatted JSON.
6. Access and print the student's city from the nested `address` dictionary.
7. Print every subject using a `for` loop.
8. Add a new subject to the `subjects` list.
