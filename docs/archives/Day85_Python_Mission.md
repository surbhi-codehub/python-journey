# 📚 Today's Topic

**Default Parameters in Functions**

### 🌟 Why are we learning this?

Sometimes a function should work even if we don't provide every value.
Default parameters let us give a ready-to-use value, making functions easier to reuse.

---

# 📖 Learn Before You Code

## What is it?

A default parameter is a value already assigned to a function parameter.
If no value is passed when calling the function, Python uses the default value.

## Why do programmers use it?

Think of ordering tea. If you don't mention sugar, the shop uses its normal amount. A default parameter works in a similar way.

## Real-Life Example

A mobile alarm rings at its default sound unless you choose a different one.

## Important Points

- Default values are written in the function definition.
- You can still provide a different value.
- They reduce repeated code.
- They make functions easier to use.
- Default values are optional.

> 💡 **Remember:** If you pass a value, it replaces the default one.

## Common Beginner Mistake

Forgetting that a value you pass overrides the default value.

## Tiny Summary

Default parameters make functions more flexible by providing ready-to-use values.
