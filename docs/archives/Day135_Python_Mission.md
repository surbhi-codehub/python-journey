# 📚 Today's Topic

## 🗑️ Making DELETE Requests

### 🌟 Why are we learning this?

Applications often need to remove outdated or unwanted data, such as deleting a user account, cancelling an order, or removing a post. APIs typically use the **DELETE** method for these operations.

# 🎉 Python Fun Fact

Most production APIs require authentication before allowing DELETE requests to prevent accidental or unauthorised data removal.

---

# 🔄 Quick Recap

- `requests.delete()` sends a DELETE request.
- The HTTP status code confirms whether the request succeeded.
- DELETE removes existing resources.
- Sensitive API operations often require authentication.
