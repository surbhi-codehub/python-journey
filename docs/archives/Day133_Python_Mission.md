# 📚 Today's Topic

## 📤 Making POST Requests

### 🌟 Why are we learning this?

POST requests are used to create new records, submit forms, register users, place orders, and send data to servers.

---

# 🚀 Today's 10 Python Missions

1. Import the `requests` library.
2. Create a dictionary named `payload` with keys like `title`, `body`, and `userId`.
3. Send a POST request to `https://jsonplaceholder.typicode.com/posts`.
4. Pass the `payload` using the `json=` parameter.
5. Store the response in a variable.
6. Print the HTTP status code.
7. Convert the response into a Python object using `.json()`.
8. Print the returned `id` from the response.
9. Display the complete response in a neatly formatted way.
10. **Revision:** Write three real-world examples where POST requests are used.

---

# 🎉 Python Fun Fact

When you create an account, submit a contact form, or publish a social media post, your app is usually sending a POST request behind the scenes.

---

# 🔄 Quick Recap

- `requests.post()` sends data to a server.
- `json=` automatically converts a dictionary into JSON.
- `.json()` reads the server's response.
- POST requests are commonly used to create new resources.
