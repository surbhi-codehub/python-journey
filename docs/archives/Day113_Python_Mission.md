# 📚 Today's Topic

## 🛤️ Introduction to the `pathlib` Module

### 🌟 Why are we learning this?

`pathlib` provides an object-oriented way to work with files and folders. It's easier to read, easier to write, and is the recommended approach in modern Python projects.

# 🎉 Python Fun Fact

The `pathlib` module was introduced to make path handling more consistent across Windows, Linux, and macOS.

---

# 🔄 Quick Recap

- `Path.cwd()` returns the current directory.
- `Path.mkdir()` creates folders.
- `Path.exists()` checks if a path exists.
- `Path` objects provide helpful attributes like `.name` and `.parent`.
