# 📚 Today's Topic

## 🗂️ Using JSON for Data Storage

### 🌟 Why are we learning this?

Text files are great for simple notes, but JSON files are better for storing structured information like users, tasks, settings, and products.

# 🚀 Today's 10 Python Missions

1. Create a file named **todo_app.py**.
2. Import Python's built-in `json` module.
3. Create an empty list named `tasks`.
4. Allow the user to add a task using `input()`.
5. Save the task list to **tasks.json** using `json.dump()`.
6. Load tasks from **tasks.json** using `json.load()`.
7. Display all saved tasks with numbering.
8. Handle the case where **tasks.json** does not yet exist.
9. Allow the user to add multiple tasks until they choose to exit.
10. **Revision:** Write three advantages of storing application data in JSON files instead of plain text files.

---

# 🎉 Python Fun Fact

Many desktop applications, browser extensions, and web services store configuration data in JSON because it's lightweight, human-readable, and easy for programs to process.

---

# 🔄 Quick Recap

- `json.dump()` writes Python objects to a JSON file.
- `json.load()` reads JSON data back into Python.
- Lists and dictionaries are stored naturally in JSON.
- JSON makes structured data easier to manage.
