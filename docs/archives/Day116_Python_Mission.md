# 📚 Today's Topic

## ⚠️ Handling Multiple Exceptions

### 🌟 Why are we learning this?

Real-world programs can encounter different kinds of errors. By handling multiple exceptions, your programs become more reliable and user-friendly.

---

# 🚀 Today's 10 Python Missions

1. Write a program that asks the user for two numbers.
2. Handle `ValueError` if the user enters invalid input.
3. Handle `ZeroDivisionError` when dividing by zero.
4. Display different messages for each exception.
5. Add an `else` block to print the division result when no error occurs.
6. Add a `finally` block that prints **"Thank you for using the program!"**.
7. Create a list and safely access an index entered by the user.
8. Handle an `IndexError` if the index is out of range.
9. Experiment by entering different invalid inputs and observe which exception is raised.
10. **Revision:** Write three reasons why handling specific exceptions is better than using one general exception.

---

# 🎉 Python Fun Fact

Professional applications often log exceptions so developers can investigate issues without the program crashing for users.

---

# 🔄 Quick Recap

- Different errors have different exception types.
- Multiple `except` blocks can handle different situations.
- `else` runs only when no exception occurs.
- `finally` always executes before the program ends.
