# 📚 Today's Topic

## 🔍 Managing CSV Records

### 🌟 Why are we learning this?

Real-world applications rarely just display data—they search for specific records, filter information, and update existing entries. These are essential data management skills.

---

# 🚀 Today's 10 Python Missions

1. Open yesterday's **student_manager.py** project.
2. Read all records from **students.csv**.
3. Ask the user to enter a student ID to search.
4. Display the matching student's details.
5. Show a friendly message if no record is found.
6. Filter and display all students whose grade is **A**.
7. Ask the user for a student ID to update.
8. Change that student's grade and save the updated data back to **students.csv**.
9. Verify the update by displaying the modified record.
10. **Revision:** Write three advantages of searching and updating records in CSV files.

# 🎉 Python Fun Fact
