# 🚀 Today's 10 Python Missions

1. Create a function that returns the area of a circle (use a fixed value of π if needed).
2. Create a function that accepts a person's age and returns whether they can vote.
3. Create a function that converts minutes into hours and minutes.
4. Create a function that accepts a price and discount percentage, then returns the final price.
5. Create a function that accepts a word and returns it in lowercase.
6. Create a function using `*args` that returns the highest number.
7. Create a function using `**kwargs` that displays employee details.
8. Create a function that calls two other functions and prints both returned results.
9. Store the return value of a function in a variable and display it.
10. **Revision:** Create a function with two parameters that returns the larger value.
