# 📚 Today's Topic

## ⏳ Using Timeouts with `requests`

### 🌟 Why are we learning this?

Sometimes a server responds slowly or stops responding. A timeout tells Python how long it should wait before giving up, making your applications faster and more reliable.

# 🎉 Python Fun Fact

Large production systems always use timeouts to prevent applications from hanging indefinitely when external services become slow.

---

# 🔄 Quick Recap

- `timeout=` limits how long Python waits.
- `try` and `except` help handle timeout errors.
- `requests.exceptions.Timeout` catches timeout-specific issues.
- Timeouts improve reliability and user experience.
