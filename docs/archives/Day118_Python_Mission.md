# 📚 Today's Topic

## 🛡️ Input Validation with Exception Handling

### 🌟 Why are we learning this?

Real-world applications must validate user input before processing it.
Combining `try`, `except`, and `raise` helps prevent invalid data from causing problems.

---

# 🚀 Today's 10 Python Missions

1. Ask the user to enter their name.
2. Raise a `ValueError` if the name is empty.
3. Ask the user to enter their age.
4. Raise a `ValueError` if the age is negative or greater than 120.
5. Ask the user to enter a positive number.
6. Handle both `ValueError` and `ZeroDivisionError` in one program.
7. Keep asking for valid input using a `while` loop until the user enters correct data.
8. Display a success message after all inputs are validated.
9. Use a `finally` block to print **"Validation complete!"**.
10. **Revision:** Write three benefits of validating user input before processing it.

---

# 🎉 Python Fun Fact

Input validation is one of the first lines of defence against software bugs and unexpected user behaviour.

---

# 🔄 Quick Recap

- Validate data before using it.
- `raise` creates meaningful exceptions.
- `try` and `except` recover from errors gracefully.
- Loops can keep asking until valid input is received.
