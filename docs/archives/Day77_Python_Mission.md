# 🚀 Today's 10 Python Missions

1. Print a hollow square of `*` with 7 rows and 7 columns.
2. Print a pyramid of `*` with 6 levels.
3. Print an inverted pyramid using `#`.
4. Display all `(row, column)` pairs where both values are even.
5. Print a 5 × 5 grid where only the border contains `X`.
6. Create a multiplication table from 1 to 10 using nested loops.
7. Print a pattern where row 1 prints `1`, row 2 prints `22`, and continue up to row 6.
8. Build a checkerboard pattern using `X` and `O`.
9. Print all number pairs from 1 to 5 where the row number is less than the column number.
10. **Revision:** Write a nested loop to print a right-angled triangle using `*`.
