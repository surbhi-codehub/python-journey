# 📚 Today's Topic

## ⚙️ Configuration Files (`config.json`)

### 🌟 Why are we learning this?

Professional applications keep configurable values—such as file paths, application names, and default settings—in configuration files. This makes programs more flexible and easier to maintain.

---

# 🚀 Today's 10 Python Missions

1. Create a file named **config.json**.
2. Add settings such as **app_name**, **data_file**, and **version**.
3. Create a file named **config_loader.py**.
4. Import Python's built-in `json` module.
5. Load the configuration using `json.load()`.
6. Display the application name and version.
7. Use the **data_file** value instead of hardcoding the CSV filename.

10. **Revision:** Write three advantages of storing settings in a configuration file.

---

# 🎉 Python Fun Fact

Many popular Python frameworks use configuration files to manage database connections, API keys, logging settings, and application behaviour without changing the program's code.

---

# 🔄 Quick Recap

- Configuration files separate settings from code.
- `json.load()` reads configuration values.
- Programs become easier to customise.
- Configuration improves maintainability and portability.
