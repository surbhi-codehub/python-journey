# 📚 Today's Topic

## 🚨 Raising Exceptions with `raise`

### 🌟 Why are we learning this?

Sometimes your program should reject invalid input even before Python raises an error.
The `raise` keyword lets you create meaningful error messages and protect your program from incorrect data.

# 🔄 Quick Recap

- `raise` creates an exception manually.
- You can raise built-in exceptions like `ValueError`.
- Custom validation prevents invalid data.
- `try` and `except` can catch exceptions that you raise yourself.
