# 📚 Today's Topic

## 📋 Using `requirements.txt`

### 🌟 Why are we learning this?

When sharing a Python project, other developers need the same libraries and versions. A `requirements.txt` file makes it easy to recreate the exact project environment.

---

# 🚀 Today's 10 Python Missions

1. Activate the virtual environment you created yesterday.
2. Install one or two packages such as `requests` and `colorama`.
3. Run `pip freeze` to view all installed packages.
4. Create a file named **requirements.txt** using:
   `pip freeze > requirements.txt`
5. Open **requirements.txt** and observe the package names and versions.
6. Create a new virtual environment in another folder.
7. Activate the new environment.
8. Install all dependencies using:
   `pip install -r requirements.txt`
9. Verify that the required packages are installed successfully.
10. **Revision:** Write three advantages of using a `requirements.txt` file.

---

# 🎉 Python Fun Fact

Open-source Python projects almost always include a `requirements.txt` file so contributors can set up the project with a single command.

---

# 🔄 Quick Recap

- `pip freeze` lists installed packages.
- `requirements.txt` stores package versions.
- `pip install -r requirements.txt` installs all dependencies.
- Dependency management improves collaboration and reproducibility.
