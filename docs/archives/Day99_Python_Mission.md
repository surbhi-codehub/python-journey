# 🚀 Today's 10 Python Missions

1. Create a function that accepts a customer's name.
2. Create a function that calculates the total price of purchased items.
3. Create a function that calculates a discount on the total amount.
4. Create a function that calculates the final bill after the discount.
5. Create a function that displays the complete bill.
6. Create a function using `*args` to calculate the total of multiple item prices.
7. Create a function using `**kwargs` to display customer information.
8. Create a main function that calls every function in the correct order.
9. Store every returned value in variables before displaying the final output.
10. **Revision:** Create a function with a default parameter that prints a thank-you message.
