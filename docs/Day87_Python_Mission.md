# 📚 Today's Topic

**Keyword Arguments**

### 🌟 Why are we learning this?

Keyword arguments let us clearly specify which value belongs to which parameter.
They make function calls easier to read and help prevent mistakes.

---

# 📖 Learn Before You Code

## What is it?

A keyword argument passes a value using the parameter's name.
Instead of relying only on the order, you tell Python exactly which parameter gets each value.

## Why do programmers use it?

Imagine filling out an online form where every box has a label like "Name" or "Email". Keyword arguments work in a similar way.

## Real-Life Example

When booking a train ticket, you enter passenger name, age, and seat preference into labelled fields. The labels help avoid confusion.

## Important Points

- Keyword arguments use parameter names.
- They improve readability.
- The order is less important when using keywords.
- They help reduce errors.
- They work well with default parameters.

> 💡 **Remember:** The parameter name comes before the value.

## Common Beginner Mistake

Using the wrong parameter name when calling the function.

## Tiny Summary

Keyword arguments make function calls clear, readable, and easier to maintain.
