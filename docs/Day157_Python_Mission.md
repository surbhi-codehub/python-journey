# 📚 Today's Topic

## 💾 File Persistence in CLI Applications

### 🌟 Why are we learning this?

Many applications need to store user data, notes, or settings. Saving data to a file makes your programs much more useful because information isn't lost when the program exits.

---

# 🚀 Today's 10 Python Missions

1. Create a file named **notes_app.py**.
2. Display a menu with options: **Add Note**, **View Notes**, and **Exit**.
3. When the user chooses **Add Note**, accept a note using `input()`.
4. Save the note to a file named **notes.txt** using append mode (`a`).
5. When the user chooses **View Notes**, open **notes.txt** in read mode.
6. Display every saved note on the screen.
7. If the file is empty or doesn't exist, display a friendly message.
8. Repeat the menu until the user selects **Exit**.
9. Add comments explaining the purpose of each function.
10. **Revision:** Write three advantages of saving application data to files.

---

# 🎉 Python Fun Fact

Simple text files are often used for logs, configuration files, and small data storage because they're easy to create, read, and edit.

---

# 🔄 Quick Recap

- Append mode (`a`) adds new content without deleting old data.
- Read mode (`r`) retrieves saved information.
- Files help applications remember data.
- Menu-driven programs become more practical with persistence.
