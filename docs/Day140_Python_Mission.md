# 📚 Today's Topic

## ⚙️ Creating Reusable API Functions

### 🌟 Why are we learning this?

Instead of writing the same API request code again and again, we can place it inside a function and call it whenever needed.

---

# 🚀 Today's 10 Python Missions

1. Import the `requests` library.
2. Create a function named `get_users()`.
3. Inside the function, send a GET request to `https://jsonplaceholder.typicode.com/users`.
4. Return the JSON response using `.json()`.
5. Call the function and store the returned data.
6. Print the total number of users.
7. Display the name of the first user.
8. Add basic error handling using `try` and `except`.
9. Add a docstring explaining what the function does.
10. **Revision:** Write three benefits of using functions for API requests.

---

# 🎉 Python Fun Fact

Well-designed functions make large projects easier to test, debug, and reuse. Professional developers often build entire libraries from reusable functions.

---

# 🔄 Quick Recap

- Functions reduce duplicate code.
- `return` sends data back to the caller.
- API logic becomes easier to reuse.
- Error handling can be included inside functions.
