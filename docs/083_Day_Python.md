# 📚 Today's Topic

**Return Values in Functions**

### 🌟 Why are we learning this?

Sometimes a function should give a result back instead of only printing it.
The `return` statement lets a function send a value that can be used later in your program.

---

# 📖 Learn Before You Code

## What is it?

A return value is the result a function sends back.
The `return` keyword ends the function and gives back a value.
You can store or use that value elsewhere.

## Why do programmers use it?

Think of using an ATM. After requesting cash, the ATM gives you money back. A function also gives back a result with `return`.

## Real-Life Example

You enter marks into a calculator. It calculates the total and returns the answer instead of only showing the steps.

## Important Points

- `return` sends a value back.
- A function can return numbers, text, or other data.
- Returned values can be stored in variables.
- `return` ends the function immediately.
- Returned values can be reused.

> 💡 **Remember:** `print()` displays a value, but `return` sends it back for later use.

## Common Beginner Mistake

Using `print()` when the task requires returning a value.

## Tiny Summary

Functions become much more useful when they return results that other parts of the program can use.
