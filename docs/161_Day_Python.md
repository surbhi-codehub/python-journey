# 📚 Today's Topic

## 📦 Building Your First Python Package

### 🌟 Why are we learning this?

As applications grow, developers organise related modules into packages. Packages make projects cleaner, easier to navigate, and more reusable.

---

# 🚀 Today's 10 Python Missions

1. Create a folder named **task_manager**.
2. Inside it, create an empty file named **__init__.py**.
3. Create a module named **tasks.py**.
4. Create another module named **storage.py**.
5. Add one simple function to **tasks.py**.
6. Add one simple function to **storage.py**.
7. Create a **main.py** file outside the package.
8. Import and call functions from both modules.
9. Run the project and verify the imports work correctly.
10. **Revision:** Write three advantages of using Python packages instead of keeping everything in one file.

---

# 🎉 Python Fun Fact

Popular libraries such as **NumPy**, **Pandas**, and **Requests** are Python packages containing many modules that work together seamlessly.

---

# 🔄 Quick Recap

- A package is a folder containing Python modules.
- `__init__.py` marks the folder as a package.
- Packages improve project organisation.
- Imports become cleaner and more structured.
