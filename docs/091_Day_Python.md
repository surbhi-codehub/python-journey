### 🌟 Why are we learning this?

The best way to remember functions is by using them.
Today's workbook helps you combine parameters, return values, default parameters, `*args`, and `**kwargs` through simple coding tasks.

---

# 🚀 Today's 10 Python Missions

1. Create a function that accepts a name and returns a welcome message.
2. Create a function that accepts two numbers and returns the larger one.
3. Create a function with a default city name and call it with and without a value.
4. Create a function using `*args` that returns the total of all numbers passed.
5. Create a function using `**kwargs` that prints every key and value.
6. Create a function that accepts a name and age, then returns a formatted sentence.
7. Create a function that accepts three subject marks and returns the average.
8. Call the same function using three different sets of values.
9. Store the return value of a function in a variable and display it.
10. **Revision:** Create a function with two parameters and call it using keyword arguments.

# 🔄 Quick Recap

- Functions organise code.
- Parameters receive values.
- `return` sends results back.
- `*args` and `**kwargs` make functions flexible.
