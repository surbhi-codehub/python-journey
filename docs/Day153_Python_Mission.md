# 📚 Today's Topic

## 📥 Understanding `sys.argv`

### 🌟 Why are we learning this?

Many Python scripts accept filenames, options, or values from the command line. `sys.argv` makes your programs more flexible and easier to automate.

# 🎉 Python Fun Fact

Many popular Python tools, including **pytest**, **black**, and **pip**, rely on command-line arguments to control their behaviour.

---

# 🔄 Quick Recap

- `sys.argv` stores command-line arguments.
- `sys.argv[0]` is the script name.
- `len(sys.argv)` counts the supplied arguments.
- Argument validation makes programs more user-friendly.
