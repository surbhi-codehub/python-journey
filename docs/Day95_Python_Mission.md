# 🚀 Today's 10 Python Missions

1. Create a function that returns the total of three numbers.
2. Create a function that accepts a student's marks and returns the highest mark.
3. Create a function that converts kilometres to metres.
4. Create a function that checks whether a number is positive, negative, or zero.
5. Create a function that returns the reverse of a word.
6. Create a function using `*args` that returns the smallest number.
7. Create a function using `**kwargs` that prints a person's profile details.
8. Create a function that calls two other functions and combines their returned values.
9. Store the returned value from a function in a variable and display it.
10. **Revision:** Create a function with a default parameter and call it with and without passing a value.

# 🎉 Python Fun Fact

Professional developers often write many small functions instead of one large function because they are easier to test, debug, and reuse.

---

# 🔄 Quick Recap

- Functions make programs organised.
- Parameters pass information.
- `return` sends results back.
- `*args` and `**kwargs` add flexibility.
