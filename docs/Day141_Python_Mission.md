# 📚 Today's Topic

## 📦 Creating and Importing Modules

### 🌟 Why are we learning this?

As your programs grow, keeping everything in one file becomes difficult. Modules help you split your code into smaller, reusable files.

# 🚀 Today's 10 Python Missions

1. Create a new file named **my_utils.py**.
2. Write a function named `greet(name)` that prints a welcome message.
3. Write another function named `add(a, b)` that returns the sum.
4. Save the module.
5. Create a new file named **main.py**.
6. Import `my_utils` into `main.py`.
7. Call the `greet()` function.
8. Call the `add()` function and print the result.
9. Try importing only the `add` function using `from my_utils import add`.
10. **Revision:** Write three benefits of using Python modules.

---

# 🎉 Python Fun Fact

The Python Standard Library is made up of hundreds of modules. Every time you use modules like `math`, `random`, or `json`, you're using reusable code written by other developers.

---

# 🔄 Quick Recap

- A module is simply a Python (`.py`) file.
- `import` lets you reuse code from another file.
- Modules keep projects clean and organised.
- Functions inside modules can be shared across multiple programs.
