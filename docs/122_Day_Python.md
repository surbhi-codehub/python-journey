# 🎉 Python Fun Fact

Large log files are usually read **line by line** instead of all at once to save memory and improve performance.

---

# 🔄 Quick Recap

- `read()` reads the entire file.
- `readline()` reads one line at a time.
- `readlines()` returns all lines as a list.
- A `for` loop is a memory-friendly way to process files line by line.
