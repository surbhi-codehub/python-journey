### 🌟 Why are we learning this?

# 🚀 Today's 10 Python Missions

1. Create a file named **menu_app.py**.
2. Display a welcome message.
3. Show a menu with four options: **Add**, **Subtract**, **Multiply**, and **Exit**.
4. Ask the user to choose an option.
5. Read two numbers using `input()`.
6. Perform the selected calculation using functions.
7. Display the result clearly.
8. Repeat the menu until the user chooses **Exit**.
9. Handle invalid menu choices with a friendly message.
10. **Revision:** Write three advantages of menu-driven CLI applications.

# 🎉 Python Fun Fact
