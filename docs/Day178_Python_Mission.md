# 📚 Today's Topic

## 🔐 Python `secrets` Module

### 🌟 Why are we learning this?

The `random` module is great for games, but it isn't designed for security. The `secrets` module creates cryptographically secure random values used in passwords, authentication, and security tokens.

# 🎉 Python Fun Fact

Many websites generate password reset links and API tokens using cryptographically secure random values to make them difficult to guess.

---

# 🔄 Quick Recap

- `secrets` is designed for security.
- `secrets.choice()` selects secure random characters.
- `token_hex()` generates secure hexadecimal tokens.
- Use `secrets` for passwords, tokens, and authentication.
