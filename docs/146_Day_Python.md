# 📚 Today's Topic

## 🏗️ Building a Simple Python Package

### 🌟 Why are we learning this?

As projects become larger, it's better to organise related modules into a package. This makes your code easier to maintain, reuse, and distribute.

---

# 🚀 Today's 10 Python Missions

1. Create a project folder named **calculator_project**.
2. Inside it, create a package folder named **calculator**.
3. Add an empty file named **`__init__.py`** inside the package.
4. Create a file named **operations.py**.
5. Write two functions: `add(a, b)` and `subtract(a, b)`.
6. Create a file named **main.py** outside the package.
7. Import the functions from the package into **main.py**.
8. Call both functions and print the results.
9. Add a short docstring to each function explaining its purpose.
10. **Revision:** Write three advantages of creating your own Python packages.

---

# 🎉 Python Fun Fact

Many famous Python libraries, such as **Flask**, **Django**, and **Pandas**, are organised into packages containing dozens or even hundreds of modules.

---

# 🔄 Quick Recap

- A package groups related Python modules.
- `__init__.py` helps define a package.
- Packages improve code organisation.
- Well-structured projects are easier to reuse and maintain.
