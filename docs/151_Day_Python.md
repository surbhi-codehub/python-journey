# 🚀 Today's 10 Python Missions

1. Create a new file named **calculator_cli.py**.
2. Display a welcome message using `print()`.
3. Ask the user to enter the first number using `input()`.
4. Ask the user to enter the second number.
5. Ask the user to choose an operation (`+`, `-`, `*`, `/`).
6. Perform the selected operation using `if-elif-else`.
7. Display the calculated result.
8. Handle division by zero with a friendly message.
9. Allow the user to run the calculator again using a loop.
