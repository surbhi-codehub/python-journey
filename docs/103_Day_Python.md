# 📚 Today's Topic

## 🎲 The `random` Module

### 🌟 Why are we learning this?

The `random` module generates random numbers and makes random selections. It's widely used in games, testing, simulations, and simple AI projects.

# 🎉 Python Fun Fact

Many online games and quiz apps use Python's `random` module to keep gameplay exciting and unpredictable.

---

# 🔄 Quick Recap

- `random.randint(a, b)` returns a random integer.
- `random.choice()` selects a random item.
- `random.random()` returns a decimal between 0 and 1.
- `random.shuffle()` rearranges a list randomly.
