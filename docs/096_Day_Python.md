# 📚 Today's Topic

**Building a Small Function-Based Program**

### 🌟 Why are we learning this?

Large programs are created by joining many small functions together.
Today you'll practise creating functions that work as a team to solve simple real-world tasks.

# 🚀 Today's 10 Python Missions

1. Create a function that calculates the total price of three items.
2. Create a function that calculates the average of five numbers.
3. Create a function that checks whether a number is divisible by 5.
4. Create a function that converts Celsius to Fahrenheit.
5. Create a function that returns the longest word from two words.
6. Create a function using `*args` that returns the average of all numbers passed.
7. Create a function using `**kwargs` that prints product details.
8. Create a function that calls two other functions and combines their returned results.
9. Store the result from a returned function in a variable and print it.
10. **Revision:** Create a function with two parameters that returns the smaller value.

# 🎉 Python Fun Fact

Breaking a big problem into many small functions is called **modular programming**, and it's a common practice in professional software development.
