# 📚 Today's Topic

## 🚨 Custom Exceptions

### 🌟 Why are we learning this?

Built-in exceptions are useful, but large applications often need their own error types. Custom exceptions make debugging easier and help communicate exactly what went wrong.

---

# 🚀 Today's 10 Python Missions

1. Create a file named **custom_exceptions.py**.
2. Create a custom exception class named `InvalidAgeError`.
3. Inherit the class from Python's built-in `Exception`.
4. Ask the user to enter their age.
5. Raise `InvalidAgeError` if the age is less than 0.
6. Display a friendly message if the age is valid.
7. Catch the custom exception using `try` and `except`.
8. Print the exception message when an error occurs.
9. Add a docstring to your custom exception class.
10. **Revision:** Write three advantages of creating custom exceptions.

# 🎉 Python Fun Fact

Many popular Python frameworks define dozens of custom exception classes so developers can quickly identify and handle specific problems.

---

# 🔄 Quick Recap

- Custom exceptions inherit from `Exception`.
- `raise` creates an exception.
- `try` and `except` handle custom errors.
- Meaningful exception names improve code readability.
