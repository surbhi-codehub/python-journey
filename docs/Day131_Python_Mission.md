# 📚 Today's Topic

## 🚀 Introduction to the `requests` Library

### 🌟 Why are we learning this?

Many applications communicate with APIs to retrieve weather updates, stock prices, user information, news, and much more. The `requests` library makes sending HTTP requests simple.

---

# 🚀 Today's 10 Python Missions

1. Install the `requests` library using `pip install requests` (or verify it's already installed).
2. Import the `requests` module.
3. Send a GET request to `https://jsonplaceholder.typicode.com/users`.
4. Store the response in a variable.
5. Print the HTTP status code.
6. Convert the response into Python data using `.json()`.
7. Print the total number of users returned.
8. Display the name of the first user.
9. Use a loop to print the names of all users.
10. **Revision:** Write three advantages of using APIs instead of manually entering data.

# 🎉 Python Fun Fact

# 🔄 Quick Recap

- `requests.get()` sends an HTTP GET request.
- `status_code` tells whether the request succeeded.
- `.json()` converts a JSON response into Python objects.
- APIs provide real-time data for applications.
