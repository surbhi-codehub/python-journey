### 🌟 Why are we learning this?

# 🚀 Today's 10 Python Missions

1. Import Python's built-in `csv` module.

3. Write a header row: `ID, Name, Department`.
4. Add at least five employee records using `csv.writer()`.

---

# 🎉 Python Fun Fact

Many business reports exported from Excel, ERP systems, and databases are stored as CSV files because they are lightweight and supported by almost every platform.

---

# 🔄 Quick Recap

- `csv.writer()` writes rows using lists.
- `csv.DictWriter()` writes rows using dictionaries.
- `writeheader()` creates the column names.
- CSV files are ideal for storing tabular data.
