# 📚 Today's Topic

**Combining Multiple Functions**

### 🌟 Why are we learning this?

Real Python programs usually contain many small functions that work together.
Instead of writing one large block of code, programmers divide work into simple, reusable functions.

# 🚀 Today's 10 Python Missions

1. Create a function that returns the square of a number.
2. Create another function that returns the cube of a number.
3. Call both functions using the same input value.
4. Create a function that accepts a student's marks and returns `"Pass"` or `"Fail"`.
5. Create a function that calculates the perimeter of a rectangle.
6. Create a function using `*args` that returns the average of all numbers passed.
7. Create a function using `**kwargs` that prints all student details.
8. Create a function that calls another function and displays its returned value.
9. Store the result from a returned function value in a variable and print it.
10. **Revision:** Create a function with a default parameter that prints a greeting.
