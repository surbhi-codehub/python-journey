# 📚 Today's Topic

## ⚙️ Using Functions in CLI Programs

### 🌟 Why are we learning this?

As applications grow, writing everything in one block becomes difficult. Functions divide your program into small, reusable pieces that are easier to understand and test.

---

# 🎉 Python Fun Fact

Professional software is often built from hundreds of small functions, each responsible for one specific task. This makes large applications easier to maintain and debug.

---

# 🔄 Quick Recap

- Functions divide large programs into smaller tasks.
- `return` sends values back to the caller.
- Small functions improve readability and reuse.
- Well-organised code is easier to test and maintain.
