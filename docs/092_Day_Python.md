### 🌟 Why are we learning this?

Today's activities focus on writing useful functions that solve everyday programming tasks.

# 🚀 Today's 10 Python Missions

1. Create a function that returns the area of a rectangle.
2. Create a function that accepts a temperature and returns whether it is hot or cold.
3. Create a function that accepts a word and returns its length.
4. Create a function that accepts three numbers and returns the smallest one.
5. Create a function that uses a default parameter for a greeting message.
6. Create a function that accepts `*args` and returns the smallest value.
7. Create a function that accepts `**kwargs` and prints every key-value pair.
8. Create a function that accepts a student's name and three marks, then returns the average.
9. Store a returned value from a function in a variable and display it.
10. **Revision:** Create a function with two parameters and return their product.

---

# 🎉 Python Fun Fact

Well-designed Python programs often use many small functions instead of one very long function because they are easier to understand and test.

---

# 🔄 Quick Recap

- Functions organise code into reusable blocks.
- Parameters receive input values.
- `return` sends results back.
- `*args` and `**kwargs` make functions flexible.
