## 🔍 Reading and Analysing CSV Data

### 🌟 Why are we learning this?

CSV files often contain thousands of records. Python helps us quickly search, filter, and summarise this data without opening Excel.

# 🎉 Python Fun Fact

Many ETL pipelines begin by reading CSV files, filtering useful records, and loading the cleaned data into databases or cloud storage.

# 🔄 Quick Recap

- `csv.reader()` reads CSV files row by row.
- Loops help process every record.
- Conditions allow you to filter specific data.
- Counting and searching are common data analysis tasks.
