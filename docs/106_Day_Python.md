# 📚 Today's Topic

## ⏱️ Mini Projects with the `time` Module

### 🌟 Why are we learning this?

The `time` module helps programs pause, measure execution time, and create countdowns. These features are useful in automation, games, reminders, and many real-world applications.

---

# 🚀 Today's 10 Python Missions

1. Import the `time` module.
2. Create a countdown timer from **10 to 1** using `time.sleep(1)`.
3. Print **"Go! 🚀"** when the countdown finishes.
4. Record the start time using `time.time()`.
5. Perform a simple calculation (such as adding numbers in a loop).
6. Record the end time and calculate how many seconds the task took.
7. Display the current date and time using `time.ctime()`.
8. Print the current hour and minute using `time.localtime()`.
9. Pause the program for **3 seconds** before printing a final message.
10. **Revision:** Write three situations where `time.sleep()` is useful.

---

# 🎉 Python Fun Fact

Many automation scripts use timed delays so they don't send requests too quickly or try to access data before it's ready.

---

# 🔄 Quick Recap

- `time.sleep()` pauses execution.
- `time.time()` measures elapsed time.
- `time.ctime()` shows a readable date and time.
- `time.localtime()` gives detailed time information.
