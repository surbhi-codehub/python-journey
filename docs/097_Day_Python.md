# 🚀 Today's 10 Python Missions

1. Create a function that returns the total marks of five subjects.
2. Create a function that returns the average of those marks.
3. Create a function that returns a grade based on the average.
4. Create a function that accepts a student's name and displays the final result.
5. Create a function that converts days into weeks and remaining days.
6. Create a function using `*args` that returns the highest number.
7. Create a function using `**kwargs` that displays employee information.
8. Create one main function that calls all the other functions in the correct order.
9. Store every returned value in separate variables and display them.
10. **Revision:** Create a function with two parameters that returns the area of a rectangle.

# 🎉 Python Fun Fact

Large software projects often contain thousands of functions, each responsible for one small task. This makes programs easier to maintain and improve.

---

# 🔄 Quick Recap

- Functions break large problems into small tasks.
- Functions can call other functions.
- Returned values can be reused.
- Small reusable functions make code easier to understand.
