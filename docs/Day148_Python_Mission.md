# 📚 Today's Topic

## ⚙️ Understanding `pyproject.toml`

### 🌟 Why are we learning this?

Modern Python projects use `pyproject.toml` to define project information, dependencies, and build settings in one place. Many new tools rely on this file.

# 🎉 Python Fun Fact

Many popular tools, including **Poetry**, **Hatch**, and modern versions of **setuptools**, use `pyproject.toml` as their primary configuration file.

---

# 🔄 Quick Recap

- `pyproject.toml` stores project metadata.
- It can define dependencies and build settings.
- Modern Python projects prefer it over using only `setup.py`.
- It helps standardise Python packaging.
