# 📚 Today's Topic

**Keyword Variable-Length Arguments (`**kwargs`)**

### 🌟 Why are we learning this?

Sometimes we don't know which named information a function will receive.
`**kwargs` lets a function accept different keyword values, making it flexible and reusable.

---

# 📖 Learn Before You Code

## What is it?

`**kwargs` allows a function to receive any number of keyword arguments.
Python collects them together so you can work with each one.
It is useful when the names or number of values may change.

## Why do programmers use it?

Imagine filling out an online profile. Some people add only a name, while others also add a city, phone number, and hobbies. One form can accept all of them.

## Real-Life Example

A customer information form can contain different details for different people. `**kwargs` helps handle those extra details.

## Important Points

- `**kwargs` accepts keyword arguments.
- The `**` symbols make it work.
- The values are grouped together.
- You can loop through them.
- It makes functions more flexible.

> 💡 **Remember:** `kwargs` is a common name, but the `**` is the important part.

## Common Beginner Mistake

Passing normal positional values instead of keyword values.

## Tiny Summary

`**kwargs` helps functions accept flexible named information without changing the function definition.
