# 📚 Today's Topic

## 🐍 Virtual Environments (`venv`)

### 🌟 Why are we learning this?

Different Python projects often require different library versions. A virtual environment keeps each project's dependencies separate, preventing conflicts and making projects easier to share.

---

# 🚀 Today's 10 Python Missions

1. Create a new folder named **my_project**.
2. Open a terminal inside the folder.
3. Create a virtual environment using `python -m venv venv`.
4. Activate the virtual environment.
5. Verify that the environment is active.
6. Install a package (for example, `requests`) using `pip`.
7. Display installed packages with `pip list`.
8. Deactivate the virtual environment using `deactivate`.
9. Reactivate it and confirm the installed package is still available.
10. **Revision:** Write three benefits of using virtual environments.

---

# 🎉 Python Fun Fact

Almost every professional Python project uses a virtual environment to ensure that teammates can work with the same package versions without affecting other projects.

---

# 🔄 Quick Recap

- `venv` creates an isolated Python environment.
- Packages installed inside it don't affect global Python.
- `pip` installs libraries into the active environment.
- `deactivate` exits the virtual environment.
