# 📚 Today's Topic

## 🧪 Working with Virtual Environments

### 🌟 Why are we learning this?

Different projects may require different package versions. A virtual environment keeps each project's dependencies separate, preventing conflicts.

---

# 🚀 Today's 10 Python Missions

4. Create a virtual environment using `python -m venv venv`.
5. Activate the virtual environment.
6. Verify that the virtual environment is active.
7. Install the **requests** package inside the virtual environment.

10. **Revision:** Write three benefits of using virtual environments.

---

# 🎉 Python Fun Fact

Most professional Python developers create a fresh virtual environment for every project to keep dependencies clean, reproducible, and easy to manage.

---

# 🔄 Quick Recap

- `python -m venv venv` creates a virtual environment.
- Activate the environment before installing packages.
- Packages installed inside `venv` don't affect other projects.
- `deactivate` exits the virtual environment.
