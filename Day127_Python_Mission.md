# 📚 Today's Topic

## 📄 Reading and Writing JSON Files

### 🌟 Why are we learning this?

Many applications save settings, user profiles, and API responses as JSON files.
Python's `json` module makes reading and writing these files simple and efficient.

---

# 🚀 Today's 10 Python Missions

1. Import Python's built-in `json` module.
2. Create a Python dictionary containing your name, age, and favourite programming language.
3. Create a file named **student.json**.
4. Save the dictionary into **student.json** using `json.dump()`.
5. Open **student.json** in read mode.
6. Load the JSON data using `json.load()`.
7. Display all the data stored in the file.
8. Access and print only the value of the `name` key.
9. Add a new key called `city`, then save the updated dictionary back into the file.
10. **Revision:** Write three differences between `json.dumps()` and `json.dump()`.

---

# 🎉 Python Fun Fact

Many mobile apps and websites use JSON files to store configuration settings because they're lightweight, portable, and easy for both humans and computers to understand.

---

# 🔄 Quick Recap

- `json.dump()` writes Python objects to a JSON file.
- `json.load()` reads JSON data from a file.
- JSON files are ideal for storing structured information.
- Dictionaries map naturally to JSON objects.
