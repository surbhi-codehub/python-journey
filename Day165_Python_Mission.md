# 📚 Today's Topic

## 📝 Python Docstrings

### 🌟 Why are we learning this?

As projects grow, it's easy to forget what a function does or how to use it. Docstrings provide built-in documentation that helps both you and other developers understand your code.

# 🎉 Python Fun Fact

Python automatically stores every function's docstring, allowing tools like IDEs and documentation generators to display helpful information instantly.

---

# 🔄 Quick Recap

- Docstrings document functions, classes, and modules.
- They are written inside triple quotes (`""" ... """`).
- `help()` displays docstrings.
- `__doc__` lets you access them programmatically.
