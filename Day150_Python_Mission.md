# 📚 Today's Topic

## 🧪 Using TestPyPI

### 🌟 Why are we learning this?

Uploading directly to the real PyPI can lead to mistakes that are difficult to fix. TestPyPI provides a safe environment where you can practise packaging and uploading without affecting real users.

---

# 🚀 Today's 10 Python Missions

1. Visit **https://test.pypi.org** and explore the website.
2. Create a free TestPyPI account.
3. Build your package using `python -m build`.
4. Verify that the `dist/` folder contains the latest package files.
5. Install **Twine** if it is not already installed.
6. Learn the command used to upload packages to TestPyPI:
   `twine upload --repository testpypi dist/*`
7. Read the upload output and identify whether the upload succeeded.
8. Install your package from TestPyPI in a new virtual environment (if available).
9. Compare TestPyPI with the real PyPI and note the differences.
10. **Revision:** Write three reasons why developers test packages before publishing them.

---

# 🎉 Python Fun Fact

Many open-source maintainers use TestPyPI as part of their release process to catch packaging issues before making a public release.

---

# 🔄 Quick Recap

- TestPyPI is a safe testing environment.
- Build packages before uploading them.
- Twine uploads distribution files securely.
- Testing reduces publishing mistakes.
