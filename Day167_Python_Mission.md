# 📚 Today's Topic

## 🪵 Python Logging

### 🌟 Why are we learning this?

Using `print()` is fine while learning, but real-world applications use logging to keep track of important events, diagnose issues, and create permanent records without cluttering the console.

# 🚀 Today's 10 Python Missions

1. Create a file named **logging_demo.py**.
2. Import Python's built-in `logging` module.
3. Configure logging using `logging.basicConfig()`.
4. Log an informational message with `logging.info()`.
5. Log a warning message with `logging.warning()`.
6. Log an error message with `logging.error()`.
7. Log a debug message with `logging.debug()`.
8. Configure logging to write messages to a file named **app.log**.
9. Run the program and open **app.log** to view the recorded messages.
10. **Revision:** Write three advantages of using logging instead of `print()` for debugging.

# 🎉 Python Fun Fact

Python's logging system supports multiple log levels—**DEBUG**, **INFO**, **WARNING**, **ERROR**, and **CRITICAL**—allowing developers to control exactly which messages are recorded.

---

# 🔄 Quick Recap

- `logging` records application events.
- Different log levels classify messages by importance.
- Logs can be written to both the console and files.
- Logging is essential for debugging and monitoring applications.
